# Deep Connect 星空主题与宇宙大爆炸开机动画设计

## 目标与体验

在现有 Deep Connect 功能与磨砂玻璃布局之上，把视觉语言升级为“星空中的轨道连接”：深空蓝紫背景、带环行星、可呼吸的轨道线，以及轻盈、可回弹的交互过渡。面板中的在线状态用轨道和星点表达，减少大面积闪烁。

DSH 启动时显示一次可跳过的宇宙大爆炸开机动画：星点从中心向外膨胀、形成星云与行星，随后自然露出应用界面。用户可在设置里重播、关闭，并能随时点“跳过”。

## 实现边界

- 星空主题仅作用于 Deep Connect 面板，不强制改变整个 DSH 的配色；普通文字继续使用主题 token。
- 开机动画使用独立的 DSH 插件，经 `shell.overlay` 插入，不能替换应用根组件，也不新建应用。
- 这是 DSH 页面加载后的启动动画，不冒充 macOS 系统启动画面，也不修改 Electron 二进制启动流程。
- 没有视频、Canvas 大图、在线图片或第三方运行时依赖；采用轻量 DOM/CSS 动画，固定随机星点，避免每帧重建。
- 减弱动态效果模式下使用静态星空和很短的淡出。
- 动画在首次显示后自动结束，设置页保留“立即重播”和“每次启动显示”开关。
- 星空视觉不是网络可达性或密钥有效性的证明；连接状态仍按现有 Host 返回的状态显示。

## 代码结构

### Deep Connect

- `plugin/client.js`：增加星空装饰组件与主题 CSS。装饰不遮挡文字、设备卡片或按钮，不改变既有连接、任务、搜索和继承行为。
- `tools/client-check.mjs`：先增加失败断言，确认星空主题、减弱动态效果、无原生遮挡；继续跑全部既有功能回归。

### 新启动插件 `dsh-cosmos-launch`

- `package.json`：插件元数据、Client 入口、图标与本地化导出。
- `cordis.patch.yml`：注册启动插件行。
- `index.js`：空 Host apply，避免依赖不必要服务。
- `client.js`：注册 `shell.overlay` 和 `settings.section`，使用 Client 存储保存首启/重播偏好，按生命周期清理定时器与监听器。
- `cosmos.js`：纯函数确定动画阶段、减弱动态效果与星点几何参数，供测试直接验证。
- `locale/{zh,en}.json`：标题、说明、跳过、重播等文案。
- `icon.svg`：原创行星与星点图标。
- `test/cosmos.test.mjs`：独立 Node 测试验证阶段、减弱动态效果、星点确定性与生命周期清理。

## 验证与交付

1. 先写失败测试并记录失败原因，再写最小实现。
2. 执行 Deep Connect 全部现有测试、cosmos 单元测试和语法检查。
3. 用 `plugin_manager install_bundle` 安装启动插件；用 Cordis Slots 确认真实 `shell.overlay` 和设置注册。
4. 本机安装 Deep Connect v4.3.0；检查更新入口与插件版本。
5. 发布对应 GitHub tag，验证 jsDelivr 安装器；不承诺未经浏览器实机观察的截图效果，报告实际可见性验证边界。
